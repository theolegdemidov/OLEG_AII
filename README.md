# OLEG AI

Помощник для создателя контента: готовит названия, описания и хэштеги на неделю вперёд, ищет тренды, разбирает твой канал и планирует публикации. **Решения всегда принимает человек**: в соцсети ничего не уходит само.

## Быстрый старт: Windows 11 (3 шага)
1. Нажми зелёную кнопку **Code → Download ZIP** на этой странице и распакуй архив.
2. Дважды щёлкни по **START.bat**. Если Python не найден, программа установит его сама (потом запусти START.bat ещё раз).
3. Ответь на три вопроса (можно пропускать клавишей Enter). Дальше появится меню с цифрами 1-5.

Что в меню:
1. **Подготовить публикации на неделю**: перетащи папку с готовыми видео в окно, получишь `pack.md` с названиями, описаниями, хэштегами и датами (по ролику в день, время разное).
2. **Найти тренды** (нужен бесплатный ключ YouTube API, шаги ниже).
3. **Разобрать мой канал**: перетащи CSV из YouTube Studio.
4. **Связать с телефоном**: покажет адрес и пароль для приложения.

## Быстрый старт: Samsung / Android (2 шага)
1. В этом репозитории: **Actions → Build Android APK → Run workflow**. Через 5-10 минут справа на главной странице появится раздел **Releases**.
2. Открой Releases с телефона, скачай **OLEG_AI.apk** и установи (Android попросит разрешить установку из этого источника).

Вкладка «План» работает без ноутбука: выбери 8-15 роликов, укажи время, получай напоминания и публикуй в один тап. Для вкладок «Тренды» и «Разбор» в «Настройках» впиши адрес и пароль из пункта 4 меню (телефон и ноутбук в одной Wi-Fi сети). Для Samsung: батарея приложения → «Без ограничений», иначе напоминания опаздывают.

## Публикация без ручной заливки
Автоматической заливки в Instagram, TikTok и YouTube здесь нет намеренно: это нарушает правила платформ. Вместо этого раз в неделю заливаешь пачку роликов во встроенные планировщики (YouTube Studio, Meta Business Suite, TikTok Studio; условия зависят от типа аккаунта) и вставляешь готовые тексты из `pack.md`.

## Бесплатный ключ YouTube API (5 минут)
console.cloud.google.com → создать проект → «YouTube Data API v3» → Включить → Учётные данные → Ключ API. Вставь в `.env` как `YOUTUBE_API_KEY`. Бесплатная квота 10 000 единиц в сутки. Без ключа работают пункты 1, 3 и 4.

## Для разработчиков
```bash
pip install -r requirements-dev.txt && python -m pytest        # 52 теста
uvicorn oleg_ai.server:create_app --factory --host 0.0.0.0 --port 8000
```
Структура: `oleg_ai/` ядро (youtube, analyzer, research, packs, telegram_export, own_stats, storage, service, video_lab, publisher, server, launcher, main), `tests/`, `mobile/` (Kotlin, Jetpack Compose), `.github/workflows/` (тесты и сборка APK). Команды CLI: `python -m oleg_ai.main --help`; анализ экспорта своего Telegram-канала: `python -m oleg_ai.telegram_export result.json`.

Безопасность: все ручки сервера требуют `X-API-Key`; загрузки ограничены по размеру и типу; секреты только в `.env` (в `.gitignore`); внешний текст в промптах помечен как данные.

## Статус и ограничения
- Python-часть покрыта тестами на подделках API; реальные ключи, реальный Gemini API и сборка под Windows автором не проверялись
- Android-код **не компилировался** в среде разработки: первая облачная сборка может потребовать правок
- Пины-видео Pinterest не реализованы; прямой автопостинг в TikTok и Instagram требует одобрения их API
- `views / subscribers` — грубый фильтр, а не доказательство вирусности
