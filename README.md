# OLEG AI

Помощник для создателя контента: ищет аномально удачные короткие ролики в нише, разбирает их через LLM, готовит идеи и черновики комментариев в авторском стиле, планирует публикации собственных видео и напоминает о них. **Человек всегда в контуре**: всё, что уходит в соцсети, подтверждает владелец.

```
 Ноутбук (Python)                          Телефон (Android, Kotlin/Compose)
 ┌──────────────────────────────┐          ┌─────────────────────────────┐
 │ YouTube Data API → поиск     │  Wi-Fi   │ Тренды: карточки, A/B-хуки, │
 │ LLM (Claude / Gemini) → разбор│◄────────►│   черновики, обратная связь │
 │ SQLite: снимки, черновики    │ X-API-Key│ План: пакет роликов → слоты │
 │ FastAPI + фоновый поиск      │          │   времени → уведомления     │
 │ Telegram: ежедневный отчёт   │          │ Мой ролик: разбор (Gemini), │
 └──────────────────────────────┘          │   «Поделиться» в один тап   │
                                           └─────────────────────────────┘
```

## Возможности
- **Trend Hunter**: отбор роликов, у которых просмотров в разы больше, чем подписчиков у канала; снимки статистики и прирост между замерами
- **Разбор через LLM**: факты, гипотезы (помечены как гипотезы), A/B-хуки, идеи анимаций, черновики комментариев; вывод нормализуется и ограничивается по длине
- **Обучение на тебе**: принятые и исправленные черновики попадают в профиль стиля
- **План публикаций** (Android, работает без ноутбука): 8–15 роликов раскладываются по дням и слотам времени со случайным сдвигом, напоминание уведомлением, публикация через системное «Поделиться»
- **Video Lab**: мультимодальный разбор собственного видеофайла через Gemini (хук первых секунд, слабые места)
- **Статистика своих роликов** из CSV (в том числе экспорт YouTube Studio): сильные и слабые ролики, удержание, время публикации, группы меньше 3 роликов помечаются «мало данных»
- **Telegram**: по одному сообщению на ролик, доставка без потерь и дублей при сбоях

## Чего здесь нет намеренно
Автокомментинга, автолистания, накрутки и обхода защит платформ. Это нарушает их правила. Комментарии и публикации в чужие приложения подтверждает человек.

## Быстрый старт (ноутбук)
```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt
cp .env.example .env                                    # заполни ключи; API_TOKEN обязателен
python -m pytest                                        # 31 тест
python -m oleg_ai.main --dry-run                        # проба без отправки и пометок
uvicorn oleg_ai.server:create_app --factory --host 0.0.0.0 --port 8000
```
Токен для `API_TOKEN`: `python -c "import secrets; print(secrets.token_urlsafe(32))"`. Сервер без токена не стартует. Разреши порт 8000 в брандмауэре только для частной сети.

Ключ YouTube Data API бесплатный: Google Cloud Console → «YouTube Data API v3» → Включить → Учётные данные → Ключ API (квота 10 000 единиц в сутки, поиск стоит 100).

## CLI
| Команда | Что делает |
|---|---|
| `python -m oleg_ai.main` | поиск, разбор новых роликов, отправка в Telegram |
| `... research` / `deliver` | только поиск или только отправка |
| `... feedback 12 accepted\|rejected\|edited "текст"` | оценка черновика (учит стиль) |
| `... import-stats файл.csv` · `own-report` | разбор своих роликов |

## Android
Сборка APK в облаке без Android Studio: вкладка **Actions → Build Android APK → Run workflow**, готовый `app-debug.apk` в разделе Artifacts. В приложении, вкладка «Настройки»: адрес `http://IP_ноутбука:8000` и `API_TOKEN`. Вкладка «План» работает без ноутбука. Для Samsung: батарея приложения → «Без ограничений», иначе напоминания опаздывают.

## Безопасность
- Все ручки сервера требуют `X-API-Key` (сравнение за постоянное время); `/health` не раскрывает данных
- Загрузки: лимит размера, белый список расширений, потоковая запись, очистка временных файлов
- Секреты только в `.env` (в `.gitignore`); внешний текст в промптах помечен как данные, а не инструкции
- Публикация собственных материалов: черновик → явное одобрение → отправка

## Статус и ограничения
- Python-ядро покрыто тестами на подделках API; реальные ключи и реальный Gemini API автором не проверялись
- Android-код **не компилировался** в среде разработки (нет Android SDK): первая облачная сборка может потребовать правок
- Пины-видео Pinterest не реализованы (только пины-картинки); прямой автопостинг в TikTok и Instagram требует одобрения их API
- Субтитры чужих видео не используются (нет официального источника); `views / subscribers` — грубый фильтр, а не доказательство вирусности
