# CLAUDE.md - OLEG AI

Python-ядро `oleg_ai/`, Android-клиент `mobile/`, тесты `tests/`.

## Правила
- Только официальные API и системные механизмы Android (Share Sheet, буфер обмена, Intent).
- Запрещено: автоматизация UI чужих приложений, имитация человека, накрутка, автокомментинг, обход антифрода,
  сбор паролей и cookies.
- Комментарии и публикации: только черновики с ручным подтверждением. Публикация своих материалов: очередь с явным approve.
- Сервер всегда требует API_TOKEN. Не ослаблять авторизацию, лимиты загрузок и белый список расширений.
- Не выдумывать метрики. Факты, гипотезы, рекомендации разделять. Не обещать вирусность.
- Секреты только в `.env`. Модели LLM только из конфигурации.
- Логику держать в модулях без веб-фреймворка и покрывать тестом. Перед выводом «работает» запускать тесты.
